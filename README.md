# نظام إدارة الامتحانات

## المتطلبات
- PHP 7.4+
- MySQL/MariaDB
- تفعيل امتدادات: PDO, mysqli, mbstring, json

## خطوات التثبيت
1. انسخ المشروع إلى مجلد الويب.
2. افتح المتصفح على `http://your-domain/install/index.php`.
3. أدخل بيانات قاعدة البيانات وحساب المشرف الأول.
4. بعد نجاح التثبيت سيتم حذف مجلد `install` تلقائيًا.
5. سجّل الدخول من `http://your-domain/admin/login.php`.

## بيانات الدخول الافتراضية
- يتم إنشاؤها أثناء التثبيت.

## هيكل المجلدات
- `admin/` لوحة التحكم.
- `api/` واجهات REST.
- `public/` الواجهة الأمامية.
- `core/` المكونات الأساسية.

## الميزات الرئيسية
- إدارة التخصصات والمواد والفصول والأسئلة.
- نظام امتحان تفاعلي بسيط.
- REST API لعمليات CRUD.

## المشاكل الشائعة
- تأكد من صلاحيات الكتابة لمجلد `config/` و `storage/`.
- تأكد من استيراد قاعدة البيانات عبر التثبيت وليس يدويًا.
